แอปถาดระบบที่ทำให้เซสชัน **Code** ของแอป Claude เดสก์ท็อปไม่หายไปเมื่อคุณสลับบัญชี Claude

แอป Claude เดสก์ท็อปเก็บรายการเซสชัน Code แยกกันตามบัญชีและองค์กร เมื่อลงชื่อเข้าด้วยบัญชีอื่น รายการจะดูว่างเปล่า ทั้งที่บทสนทนายังอยู่ในคอมพิวเตอร์ CCDC จะคัดลอกเซสชันข้ามไปให้ ไม่ว่าบัญชีใดลงชื่อเข้าถัดไปก็จะเห็นเซสชันทั้งหมด

เครื่องมือที่ไม่เป็นทางการ ไม่มีส่วนเกี่ยวข้องและไม่ได้รับการรับรองจาก Anthropic

**[ดาวน์โหลดรุ่นล่าสุด](../../releases/latest)** · Windows 10/11 · macOS 11+ · Ubuntu/Debian/Linux Mint · ไม่ต้องติดตั้งอะไรเพิ่ม

| macOS | 0.2 | ใหม่ ยังไม่ได้ทดสอบกับแอป Claude จริงบน Mac |

## เหมาะกับใคร

- **คอมพิวเตอร์ใช้ร่วมกันและการทำงานเป็นกะ** ในสถานที่ทำงานที่เปิด 24 ชั่วโมงแบบสามกะ แต่ละกะจะมีคนต่างกันนั่งที่โต๊ะเดียวกัน (คอมพิวเตอร์เครื่องเดียว ผู้ใช้ระบบคนเดียว) และลงชื่อเข้าด้วยบัญชี Claude ของตัวเอง เมื่อใช้ CCDC กะถัดไปก็ทำงาน Code ต่อจากที่กะก่อนหน้าทิ้งไว้ได้
- **คนเดียว หลายบัญชี** หากคุณสลับไปมาระหว่างบัญชีส่วนตัวกับบัญชีงาน หรือระหว่างองค์กรบนคอมพิวเตอร์เครื่องเดียวกัน เซสชัน Code ของคุณจะอยู่ครบไม่ว่าจะลงชื่อเข้าด้วยบัญชีใด

ทุกบัญชีที่ลงชื่อเข้าบนคอมพิวเตอร์เครื่องนี้จะเห็นเซสชัน Code ทั้งหมดในเครื่อง อย่าใช้ CCDC ในที่ที่แต่ละคนต้องไม่เห็นเซสชันของกันและกัน หากใช้บัญชีบริษัท (องค์กร) โปรดตรวจสอบนโยบายของบริษัทก่อน เพราะ CCDC จะคัดลอกเซสชันของบัญชีงานไปไว้ในโฟลเดอร์ของบัญชีส่วนตัวด้วย และในทางกลับกันก็เช่นกัน

## ปัญหาที่แก้

แอปเดสก์ท็อปเก็บ**รายการ**เซสชัน Code แยกโฟลเดอร์ตามบัญชีและองค์กร:

```
<Claude data folder>/claude-code-sessions/<accountUuid>/<orgUuid>/local_<id>.json
```

| | โฟลเดอร์ข้อมูลของ Claude | บันทึกของ Claude |
| --- | --- | --- |
| Windows | `%LOCALAPPDATA%\Claude-Data\claude_<pkg>` (หรือ `%APPDATA%\Claude`) | `%LOCALAPPDATA%\Claude\Logs\main.log` |
| macOS | `~/Library/Application Support/Claude` | `~/Library/Logs/Claude/main.log` |
| Linux | `~/.config/Claude` | `~/.config/Claude/logs/main.log` |

(องค์กรที่ใช้ Claude ผ่านผู้ให้บริการคลาวด์ของตนเองจะใช้ `Claude-3p` แทน `Claude` และ CCDC ก็ค้นหาที่นั่นด้วย)

ส่วน**บทสนทนา**เองอยู่ใน `~/.claude/projects/.../<cliSessionId>.jsonl` ซึ่งทุกบัญชีใช้ร่วมกัน ดังนั้นหลังจากมีคนลงชื่อเข้าด้วยบัญชีอื่น รายการเซสชัน Code จะดูว่างเปล่า ทั้งที่บทสนทนายังอยู่ในดิสก์

## วิธีการทำงาน

แอปอ่านโฟลเดอร์เซสชัน**เฉพาะตอนเริ่มทำงานและตอนมีคนลงชื่อเข้าเท่านั้น** (สองครั้งภายในประมาณสองวินาที) และไม่มีวิธีสั่งให้แอปโหลดเฉพาะรายการเซสชันซ้ำในภายหลัง บันทึกของแอปเองจดทั้งสองเหตุการณ์นี้ไว้:

- ออกจากระบบ: `[account] Login-state transition (loggedOut: false → true ...)`
- ลงชื่อเข้า: `[LocalSessionManager] Initialization succeeded — accountId=…, orgId=…`

CCDC ติดตามบันทึกนั้นและทำงานดังนี้:

1. **ออกจากระบบ** → คัดลอกเวอร์ชันล่าสุดของทุกเซสชันไปยังโฟลเดอร์ของทุกบัญชี/องค์กร บัญชีที่ลงชื่อเข้าถัดไปจึงพบเซสชันในโฟลเดอร์ของตัวเองอยู่แล้ว โดยจะคัดลอกเฉพาะเซสชันที่ยังไม่มีหรือล้าสมัยในโฟลเดอร์นั้น
2. **ลงชื่อเข้า** → โดยค่าเริ่มต้นสำเนาจะอยู่ที่เดิม หากเปิด "ลบสำเนาหลังลงชื่อเข้า" CCDC จะรอจนแอปอ่านรายการเสร็จ (6 วินาทีหลังบรรทัดลงชื่อเข้าสุดท้าย) แล้วลบสำเนาทุกที่ ยกเว้นโฟลเดอร์ของบัญชีที่ลงชื่อเข้าอยู่

เซสชันที่ลบในแอปจะถูกลบจากโฟลเดอร์อื่นด้วย จึงไม่กลับมาปรากฏภายใต้บัญชีอื่น

ก่อนคัดลอก CCDC จะตรวจพื้นที่ดิสก์ว่าง หากไม่มีพื้นที่พอสำหรับสำเนาบวก 512 MB จะไม่คัดลอกอะไรเลยและแสดงคำเตือน

### ทำไมจึงเก็บสำเนาไว้ตามค่าเริ่มต้น

การเก็บสำเนาไว้เป็นทางเลือกที่ถนอม SSD ที่สุด:

- **เก็บสำเนา (ค่าเริ่มต้น)**: การออกจากระบบครั้งแรกจะคัดลอกทุกเซสชันหนึ่งครั้ง หลังจากนั้นทุกครั้งที่ออกจากระบบจะเขียนเฉพาะเซสชันที่เปลี่ยนจากครั้งก่อน ซึ่งมักเป็นไม่กี่ไฟล์และไม่กี่ MB และเสร็จเกือบทันที
- **ลบสำเนาหลังลงชื่อเข้า**: ทุกครั้งที่ลงชื่อเข้าจะลบสำเนา ทุกครั้งที่ออกจากระบบจึงต้องเขียนทุกเซสชันใหม่ หากมีประมาณ 300 เซสชันและ 10 โฟลเดอร์บัญชี/องค์กร นั่นคือเขียนราว 600 MB ทุกครั้งที่เปลี่ยนกะ บวกกับการลบไฟล์ราว 3,000 ไฟล์ภายหลัง

สิ่งที่ต้องแลกคือพื้นที่ดิสก์: สำเนาจะยังคงอยู่และใช้พื้นที่ประมาณ (ขนาดรวมของไฟล์เซสชัน × จำนวนโฟลเดอร์บัญชี/องค์กร)

### ทำไมไม่ใช้จังก์ชันหรือฮาร์ดลิงก์

หากให้โฟลเดอร์ของทุกบัญชีชี้ไปยังโฟลเดอร์จริงโฟลเดอร์เดียว ก็ไม่ต้องคัดลอก แต่แอป Claude ตั้งใจปิดกั้นทั้งสองวิธีไว้:

- **จังก์ชันและลิงก์สัญลักษณ์**: ก่อนบันทึกทุกครั้ง แอปจะตรวจว่าโฟลเดอร์เซสชันเป็นโฟลเดอร์จริง และปฏิเสธการบันทึกหากเป็นลิงก์ (`Refusing non-directory at private dir path (symlink/file plant)`) เมื่อทดสอบกับแอปจริง อ่านรายการผ่านจังก์ชันได้ แต่การบันทึกเซสชันและงานตามกำหนดเวลาล้มเหลวทั้งหมด รวมถึงเซสชันที่เพิ่งสร้าง
- **ฮาร์ดลิงก์**: แอปถือว่าไฟล์ที่มีลิงก์มากกว่าหนึ่งไม่ปลอดภัย จึงปฏิเสธการเขียนลงไฟล์เหล่านั้นและเตือนเมื่ออ่าน อีกทั้งแอปบันทึกด้วยการเขียนไฟล์ชั่วคราวแล้วเปลี่ยนชื่อ ซึ่งจะทำให้ลิงก์ขาดทุกครั้งที่บันทึก

การตรวจสอบเหล่านี้มีไว้ป้องกันไฟล์หรือโฟลเดอร์ที่ถูกวางไว้จากภายนอก CCDC จึงไม่หลีกเลี่ยงการตรวจสอบเหล่านี้ แต่คัดลอกไฟล์ธรรมดาแบบเดียวกับที่แอปเขียนเอง

## การติดตั้ง

ดาวน์โหลดไฟล์สำหรับระบบของคุณจาก [Releases](../../releases) ไฟล์เหล่านี้ไม่ได้ลงนามโค้ด (ดู[ด้านล่าง](#เกี่ยวกับคำเตือนด้านความปลอดภัย))

**Windows** — เรียกใช้ `CCDC-<version>-windows-x64.msi` ไม่ต้องใช้สิทธิ์ผู้ดูแลระบบ

- ติดตั้งไว้ที่ `%LOCALAPPDATA%\Programs\CCDC` สร้างทางลัด `Continuous Claude Desktop Code` บนเดสก์ท็อปและในเมนูเริ่ม แล้วเริ่ม CCDC ในถาดระบบ
- เริ่มทำงานพร้อมคอมพิวเตอร์ หากไม่ต้องการ ให้ปิด "เริ่มทำงานพร้อมคอมพิวเตอร์" ในเมนูถาดระบบ
- การอัปเดต: เรียกใช้ `.msi` เวอร์ชันใหม่กว่า ตัวติดตั้งจะปิด CCDC แทนที่ไฟล์ แล้วเริ่มใหม่ โดยการตั้งค่าของคุณยังคงอยู่
- ถอนการติดตั้งได้ใน การตั้งค่า > แอป > แอปที่ติดตั้ง > "Continuous Claude Desktop Code (CCDC)"
- หากเคยใช้สคริปต์เวอร์ชัน 0.3: ติดตั้ง `.msi` ได้เลย เมื่อเริ่มครั้งแรก CCDC จะหยุดเวอร์ชันเก่า เก็บการตั้งค่าและชื่อบัญชีไว้ แล้วลบเวอร์ชันเก่าออก

**macOS** — เปิด `CCDC-<version>-macos-universal.dmg` แล้วลาก **CCDC** ไปไว้ใน Applications จากนั้นเปิดแอป ตัว **C** จะปรากฏในแถบเมนู แอปจะเริ่มทำงานพร้อมคอมพิวเตอร์ เว้นแต่คุณจะปิดในเมนูของแอป ใช้ได้ทั้ง Apple Silicon และ Intel

**Linux** (Ubuntu 22.04+, Debian 12+, Linux Mint 21+, x86_64):

```sh
sudo apt install ./CCDC-<version>-linux-amd64.deb
```

จากนั้นเปิด **Continuous Claude Desktop Code** จากเมนูแอปพลิเคชัน แอปจะเริ่มทำงานพร้อมคอมพิวเตอร์ เว้นแต่คุณจะปิดในเมนูของแอป บน GNOME ที่ไม่มีส่วนขยาย AppIndicator ไอคอนถาดระบบจะแสดงไม่ได้ (Ubuntu และ Linux Mint มีส่วนขยายนี้มาให้แล้ว)

การถอนการติดตั้งจะคงไฟล์เซสชันของ Claude การตั้งค่าของ CCDC และโฟลเดอร์สำรองไว้ตามเดิม

### เกี่ยวกับคำเตือนด้านความปลอดภัย

การลงนามโค้ดต้องใช้ใบรับรองแบบเสียเงินที่ผูกกับบุคคลหรือบริษัท แต่ CCDC เป็นโปรเจกต์ฟรีขนาดเล็ก ไฟล์ดาวน์โหลดจึงไม่ได้ลงนาม ระบบจะเตือนคุณในครั้งแรก ซึ่งหมายความเพียงว่ายังยืนยันตัวตนผู้เผยแพร่ไม่ได้ ไม่ได้หมายความว่าพบสิ่งที่เป็นอันตราย

CCDC ไม่มีสิ่งที่เป็นอันตราย ไม่เชื่อมต่ออินเทอร์เน็ต ไม่เก็บข้อมูล และไม่เปลี่ยนแปลงสิ่งใดนอกโฟลเดอร์เซสชันของแอป Claude และโฟลเดอร์ของตัวเอง โค้ดทั้งหมดอยู่ในที่เก็บนี้ และไฟล์รุ่นเผยแพร่สร้างจากโค้ดนี้โดย GitHub Actions ซึ่งเปิดบันทึกให้ทุกคนดูได้ คุณตรวจสอบไฟล์ที่ดาวน์โหลดเทียบกับ `SHA256SUMS.txt` ในรุ่นเผยแพร่ได้ หรือจะ[บิลด์เอง](#การบิลด์)ก็ได้

- **Windows**: หาก SmartScreen แจ้งว่า "Windows ปกป้องพีซีของคุณแล้ว" ให้คลิก **ข้อมูลเพิ่มเติม** แล้วคลิก **เรียกใช้ต่อไป**
- **macOS**: หาก macOS แจ้งว่าตรวจสอบแอปไม่ได้ ให้เปิด **การตั้งค่าระบบ > ความเป็นส่วนตัวและความปลอดภัย** เลื่อนลงแล้วคลิก **เปิดต่อไป** ข้าง CCDC (หรือเรียกใช้ `xattr -dr com.apple.quarantine /Applications/CCDC.app` ใน Terminal)
- **Linux**: แพ็กเกจ `.deb` ไม่ได้ถูกตรวจสอบในลักษณะนี้

## แอปถาดระบบ

ไอคอนตัว **C** สีส้มจะปรากฏในพื้นที่แจ้งเตือนหรือแถบเมนู (เป็นสีเทาขณะปิดการซิงค์อัตโนมัติ) คลิกเพื่อเปิดเมนู:

| เมนู | หน้าที่ |
| --- | --- |
| บรรทัดสถานะ | แสดงว่า CCDC กำลังเฝ้าดูการลงชื่อเข้าและออกจากระบบอยู่หรือไม่ |
| บรรทัดเวลาลงชื่อเข้า | แสดงบัญชีที่ออกจากระบบอยู่บัญชีละหนึ่งบรรทัด ว่าลงชื่อเข้าเมื่อกี่ชั่วโมงกี่นาทีที่แล้ว (เช่น "ลงชื่อเข้าเมื่อ 2 ชม. 13 นาทีที่แล้ว") เพื่อช่วยคาดว่าบัญชีนั้นอยู่ช่วงไหนของรอบการใช้งาน 5 ชั่วโมงของ Claude |
| ซิงค์อัตโนมัติ (ตรวจจับการลงชื่อเข้า/ออก) | เปิดหรือปิดการคัดลอกและการล้างสำเนา |
| ย้ายเซสชันไปยังบัญชีตอนนี้ | แสดงเมื่อเปิด "ลบสำเนาหลังลงชื่อเข้า" ใช้เมื่อตรวจไม่พบการออกจากระบบ: รวมเซสชันทั้งหมดไว้ในโฟลเดอร์ของบัญชีเดียว จะถามยืนยันก่อนหากบัญชีนั้นไม่ได้ลงชื่อเข้าอยู่ |
| ซิงค์ทุกบัญชีตอนนี้ | แสดงในตำแหน่งเดียวกันเมื่อปิด "ลบสำเนาหลังลงชื่อเข้า" ใช้เมื่อตรวจไม่พบการออกจากระบบ: คัดลอกเซสชันทั้งหมดไปยังโฟลเดอร์ของทุกบัญชี เหมือนตอนออกจากระบบ |
| ลบสำเนาหลังลงชื่อเข้า | ปิดไว้ตามค่าเริ่มต้น (เก็บสำเนาไว้ ดูด้านบน) |
| ความเร็วในการคัดลอก/ลบ | เลือกได้ระหว่าง เร็ว (ไม่จำกัด), ปกติ (60 MB/s) และ ช้า (15 MB/s) ในโหมดปกติและช้า การลบจะจำกัดไว้ที่ 500 และ 100 ไฟล์ต่อวินาทีตามลำดับ |
| บรรทัดเวลาโดยประมาณ | แสดงเวลาที่การคัดลอกตอนออกจากระบบครั้งถัดไปจะใช้ หากตั้งให้ลบสำเนา จะแสดงเวลาที่ใช้ล้างหลังลงชื่อเข้าด้วย |
| เริ่มทำงานพร้อมคอมพิวเตอร์ | เริ่ม CCDC เมื่อคุณลงชื่อเข้าคอมพิวเตอร์ |
| Language | เลือกภาษาที่แสดง รายการนี้แสดงเป็นภาษาอังกฤษเสมอ และแต่ละภาษาในเมนูย่อยเขียนด้วยภาษานั้นเอง |
| ดูบันทึก | เปิด `watch.log` ของ CCDC |
| ตั้งชื่อบัญชี (ccdc.json) | เปิดไฟล์ตั้งค่าเพื่อตั้งชื่อบัญชีให้อ่านง่าย |
| ออก | นำไอคอนออก หากกำลังคัดลอกอยู่ จะรอให้เสร็จก่อน |

จะมีการแจ้งเตือนเมื่อเริ่มคัดลอก (พร้อมเวลาโดยประมาณ) เมื่อคัดลอกเสร็จ เมื่อตรวจพบการลงชื่อเข้า และเมื่อล้างเสร็จ หากเลือกความเร็วที่ต่ำลง การคัดลอกจะใช้เวลานานขึ้น คนถัดไปจึงควรรอการแจ้งเตือน "คัดลอกเสร็จแล้ว" หรือรอตามเวลาโดยประมาณก่อนลงชื่อเข้า

เวลาโดยประมาณคำนวณจากสถานะปัจจุบันของโฟลเดอร์ และจากความเร็วในการคัดลอกและลบที่วัดได้บนคอมพิวเตอร์เครื่องนี้ (เก็บไว้ใน `state.json` ในโฟลเดอร์ของ CCDC)

หากไม่เห็นไอคอนใน Windows 11 ให้ดูในไอคอนที่ซ่อนอยู่ (`^`) บนแถบงาน หากต้องการให้แสดงตลอด ให้เปิด CCDC ใน การตั้งค่า > การปรับให้เป็นแบบส่วนตัว > แถบงาน > ไอคอนถาดระบบอื่นๆ

CCDC เป็นโปรแกรมเนทีฟไฟล์เดียวขนาดประมาณ 1 MB ระหว่างรอ แอปจะอ่านเฉพาะส่วนที่เพิ่มเข้ามาในบันทึกของ Claude นับจากการตรวจครั้งก่อน ทุกครึ่งวินาที และใช้หน่วยความจำของตัวเองราว 4 MB

## การตั้งค่า

การตั้งค่าเก็บไว้ใน `ccdc.json` ในโฟลเดอร์ของ CCDC:

| | โฟลเดอร์ของ CCDC |
| --- | --- |
| Windows | `%LOCALAPPDATA%\CCDC` |
| macOS | `~/Library/Application Support/CCDC` |
| Linux | `~/.config/ccdc` |

ค่าที่เปลี่ยนจากเมนูถาดระบบจะบันทึกลงไฟล์นี้ และมีผลตั้งแต่การคัดลอกหรือการล้างครั้งถัดไปโดยไม่ต้องรีสตาร์ท `watch.log` และ `state.json` ก็อยู่ในโฟลเดอร์เดียวกัน

```json
{
  "keepCopies": true,
  "speed": "fast",
  "language": "",
  "startAtLogin": true,
  "aliases": { "<first 8 characters of an account ID>": "<name>" }
}
```

| คีย์ | ค่า |
| --- | --- |
| `keepCopies` | `true` (ค่าเริ่มต้น): เก็บสำเนาไว้ `false`: ลบสำเนาหลังลงชื่อเข้า |
| `speed` | `"fast"` (ค่าเริ่มต้น), `"normal"`, `"gentle"` |
| `language` | เว้นว่างเพื่อใช้ภาษาตามระบบ หรือใส่รหัสภาษา เช่น `"ja"` เพื่อใช้ภาษานั้น |
| `startAtLogin` | ตั้งค่าจาก "เริ่มทำงานพร้อมคอมพิวเตอร์" ในเมนูถาดระบบ |
| `aliases` | ชื่อที่แสดงสำหรับบัญชีในเมนูถาดระบบ |
| `dataDir`, `appLog` | ใช้เฉพาะเมื่อ CCDC หาโฟลเดอร์ข้อมูลหรือบันทึกของ Claude เองไม่พบ: ใส่พาธเต็มของแต่ละรายการ |

## ภาษา

เมนูถาดระบบ การแจ้งเตือน และคำเตือนจะใช้ภาษาที่แสดงของระบบ หรือภาษาที่เลือกไว้ใน **Language** ในเมนูถาดระบบ ภาษาที่รองรับ: อังกฤษ เกาหลี ญี่ปุ่น จีน (ตัวย่อและตัวเต็ม) สเปน ฝรั่งเศส เยอรมัน อิตาลี โปรตุเกส รัสเซีย ยูเครน โปแลนด์ ดัตช์ ตุรกี เวียดนาม อินโดนีเซีย ไทย อาหรับ และฮินดี ภาษาอื่นจะแสดงเป็นภาษาอังกฤษ

ข้อความทั้งหมดของอินเทอร์เฟซอยู่ในชีตเดียว [`locales.csv`](locales.csv) ซึ่งรวมอยู่ในโปรแกรม: **หนึ่งแถวต่อหนึ่งภาษา** หนึ่งคอลัมน์ต่อหนึ่งข้อความ เปิดด้วย Excel หรือ Google ชีตได้ หากต้องการเพิ่มภาษา ให้เพิ่มหนึ่งแถวแล้ว[บิลด์](#การบิลด์) CCDC

- `lang`: แท็กภาษา (`sv`, `pt-BR`, `zh-Hant` …) จะใช้แถวที่ตรงทั้งภาษาและภูมิภาคก่อน หากไม่มีจึงใช้แถวที่ตรงกับภาษา
- `name`: ชื่อภาษาที่เขียนด้วยภาษานั้น (`Svenska`) เมนู Language จะแสดงชื่อนี้
- เขียนการขึ้นบรรทัดใหม่ในเซลล์เป็น `\n` และคง `{0}`, `{1}` ไว้ (เป็นตำแหน่งที่ใส่ตัวเลขหรือชื่อ)
- เซลล์ว่างจะแสดงเป็นภาษาอังกฤษ ให้บันทึกไฟล์เป็น CSV แบบ UTF-8

ผลลัพธ์บรรทัดคำสั่งและ `watch.log` ยังคงเป็นภาษาอังกฤษ

## บรรทัดคำสั่ง

โปรแกรมเดียวกันนี้ใช้จากเทอร์มินัลได้ด้วย (บน Windows คือ `ccdc.exe` ใน `%LOCALAPPDATA%\Programs\CCDC` บน macOS คือ `/Applications/CCDC.app/Contents/MacOS/ccdc`):

```sh
ccdc status               # app state, settings, sessions per folder, last sign-in times, free disk
ccdc estimate             # how long the next sign-out copy / sign-in cleanup would take
ccdc replicate --dry-run  # what a sign-out copy would write right now
ccdc move [--to <acct>]   # gather every session into one account's folder (first 8 characters of the ID are enough)
ccdc watch                # follow the Claude log in the foreground, without the tray
ccdc version
```

ใช้ `--data-dir <path>` และ `--app-log <path>` เพื่อระบุโฟลเดอร์ข้อมูลหรือบันทึกของ Claude เอง

## กฎการจัดการสำเนาซ้ำ

- หากเซสชันอยู่ในหลายโฟลเดอร์ จะใช้สำเนาที่มี `lastActivityAt` ล่าสุด สำเนาจะคงเวลาแก้ไขของต้นฉบับไว้ จึงรู้ได้ว่าสำเนาใดเหมือนกันจากขนาดและเวลาโดยไม่ต้องอ่านไฟล์
- เมื่อสำเนาที่ใหม่กว่าแทนที่ไฟล์ ไฟล์เดิมจะถูกย้ายไปที่ `ccdc-backups/<time>/` ในโฟลเดอร์ข้อมูลของ Claude
- เซสชันที่มีเครื่องหมาย `deleted_<id>` จะไม่ถูกคัดลอก และสำเนาในโฟลเดอร์อื่นจะถูกลบ
- บัญชี/องค์กรที่ลงชื่อเข้าเป็นครั้งแรกยังไม่มีโฟลเดอร์ จึงคัดลอกไปไว้ที่นั่นตอนออกจากระบบไม่ได้ ในกรณีนี้ เซสชันจะแสดงหลังบัญชีนั้นลงชื่อเข้าครั้งถัดไปหรือเมื่อรีสตาร์ทแอป

## ข้อควรระวัง

- CCDC อาศัยโครงสร้างไฟล์ภายในและข้อความบันทึกของแอป Claude เดสก์ท็อป การอัปเดตแอปอาจทำให้การทำงานเปลี่ยนไป
- ไฟล์เซสชันมีการตั้งค่าตัวเชื่อมต่อ (MCP) ของแต่ละบัญชี ตัวเชื่อมต่อบางตัวจึงอาจเชื่อมต่อไม่ได้เมื่อเปิดเซสชันจากบัญชีอื่น
- งานตามกำหนดเวลาไม่ได้ใช้ร่วมกันระหว่างบัญชี แต่ละโฟลเดอร์บัญชี/องค์กรเก็บงานของตัวเองแยกกัน
- ไม่ครอบคลุมการสลับบัญชีใน Claude Code CLI เพราะ CLI เปิดเซสชันใดก็ได้ใน `~/.claude/projects` ด้วย `--resume` อยู่แล้ว ไม่ว่าจะเป็นบัญชีใด

## การบิลด์

CCDC เขียนด้วย Rust ให้[ติดตั้ง Rust](https://rustup.rs) ก่อน แล้วเรียกใช้:

```sh
cargo build --release                                    # the program (target/release/ccdc)
powershell -File packaging\windows\build-msi.ps1         # Windows .msi (needs the .NET SDK)
sh packaging/macos/make-dmg.sh                           # macOS .dmg (on a Mac)
sh packaging/linux/build-deb.sh                          # Linux .deb (on Ubuntu 22.04, or in Docker:)
docker run --rm -v "$PWD:/w" -w /w ubuntu:22.04 sh packaging/linux/build-deb.sh
```

เวอร์ชันของแต่ละแพลตฟอร์มกำหนดไว้ใน `[package.metadata.ccdc]` ใน `Cargo.toml` ส่วน GitHub Actions ([`.github/workflows/build.yml`](.github/workflows/build.yml)) จะบิลด์ทั้งสามแพลตฟอร์มทุกครั้งที่ push และเมื่อมีแท็ก `v*` จะแนบไฟล์ไว้กับรุ่นเผยแพร่ฉบับร่าง
