# Continuous Claude Desktop Code (CCDC)

[English](README.md) | [한국어](README.ko.md) | [日本語](README.ja.md) | [简体中文](README.zh-Hans.md) | [繁體中文](README.zh-Hant.md) | [Español](README.es.md) | [Français](README.fr.md) | [Deutsch](README.de.md) | [Italiano](README.it.md) | [Português](README.pt.md) | [Русский](README.ru.md) | [Українська](README.uk.md) | [Polski](README.pl.md) | [Nederlands](README.nl.md) | [Türkçe](README.tr.md) | [Tiếng Việt](README.vi.md) | [Bahasa Indonesia](README.id.md) | **ไทย** | [العربية](README.ar.md) | [हिन्दी](README.hi.md)

แอปถาดระบบสำหรับ Windows ที่ทำให้เซสชัน **Code** ในเครื่องของแอป Claude เดสก์ท็อปพร้อมใช้งานสำหรับทุกบัญชี Claude ที่ลงชื่อเข้าบนพีซีเครื่องนี้

เครื่องมือที่ไม่เป็นทางการ ไม่มีส่วนเกี่ยวข้องและไม่ได้รับการรับรองจาก Anthropic

## เหมาะกับใคร

CCDC สร้างขึ้นสำหรับ **สถานที่ทำงานที่เปิด 24 ชั่วโมงแบบสามกะ** ในแต่ละกะจะมีคนต่างกันนั่งที่โต๊ะเดียวกัน (พีซีเครื่องเดียว ผู้ใช้ Windows คนเดียว) และลงชื่อเข้าแอป Claude เดสก์ท็อปด้วยบัญชี Claude ของตัวเอง เมื่อใช้ CCDC คนในกะถัดไปลงชื่อเข้าแล้วทำงาน Code ต่อจากที่กะก่อนหน้าทิ้งไว้ได้ทันที

ด้วยเหตุนี้ ทุกคนที่ลงชื่อเข้าบนพีซีเครื่องนี้จะเห็นเซสชัน Code ทั้งหมด อย่าใช้ CCDC ในที่ที่แต่ละคนต้องไม่เห็นเซสชันของกันและกัน หากเป็นบัญชีบริษัท (องค์กร) โปรดตรวจสอบนโยบายของบริษัทด้วย

## ปัญหาที่แก้

แอปเดสก์ท็อปเก็บ**รายการ**เซสชัน Code แยกโฟลเดอร์ตามบัญชีและองค์กร:

```
%LOCALAPPDATA%\Claude-Data\claude_<pkg>\claude-code-sessions\<accountUuid>\<orgUuid>\local_<id>.json
```

ส่วน**บทสนทนา**เองอยู่ใน `~/.claude/projects\...\<cliSessionId>.jsonl` ซึ่งทุกบัญชีใช้ร่วมกัน ดังนั้นหลังจากมีคนลงชื่อเข้าด้วยบัญชีอื่น รายการเซสชัน Code จะดูว่างเปล่า ทั้งที่บทสนทนายังอยู่ในดิสก์

## วิธีการทำงาน

แอปอ่านโฟลเดอร์เซสชัน**เฉพาะตอนเริ่มทำงานและตอนมีคนลงชื่อเข้าเท่านั้น** (สองครั้งภายในประมาณสองวินาที) และไม่มีวิธีสั่งให้แอปโหลดเฉพาะรายการเซสชันซ้ำในภายหลัง บันทึกของแอปเอง `%LOCALAPPDATA%\Claude\Logs\main.log` จดทั้งการออกจากระบบและการลงชื่อเข้าไว้:

- ออกจากระบบ: `[account] Login-state transition (loggedOut: false → true ...)`
- ลงชื่อเข้า: `[LocalSessionManager] Initialization succeeded — accountId=…, orgId=…`

CCDC ติดตามบันทึกนั้นและทำงานดังนี้:

1. **ออกจากระบบ** → คัดลอกเวอร์ชันล่าสุดของทุกเซสชันไปยังโฟลเดอร์ของทุกบัญชี/องค์กร ไม่ว่าบัญชีใดลงชื่อเข้าถัดไป ก็จะพบเซสชันในโฟลเดอร์ของบัญชีนั้นอยู่แล้ว โดยจะคัดลอกเฉพาะเซสชันที่ยังไม่มีหรือล้าสมัยในโฟลเดอร์นั้น
2. **ลงชื่อเข้า** → โดยค่าเริ่มต้นสำเนาจะอยู่ที่เดิม หากเปิด "ลบสำเนาหลังลงชื่อเข้า" CCDC จะรอจนแอปอ่านรายการเสร็จ (6 วินาทีหลังบรรทัดลงชื่อเข้าสุดท้าย) แล้วลบสำเนาทุกที่ ยกเว้นโฟลเดอร์ของบัญชีที่ลงชื่อเข้าอยู่

เซสชันที่ลบในแอปจะถูกลบจากโฟลเดอร์อื่นด้วย จึงไม่กลับมาปรากฏภายใต้บัญชีอื่น

ก่อนคัดลอก CCDC จะตรวจพื้นที่ดิสก์ว่าง หากไม่มีพื้นที่พอสำหรับสำเนาบวก 512 MB จะไม่คัดลอกอะไรเลยและแสดงคำเตือน

### ทำไมจึงเก็บสำเนาไว้ตามค่าเริ่มต้น

การเก็บสำเนาไว้เป็นทางเลือกที่ถนอม SSD ที่สุด:

- **เก็บสำเนา (ค่าเริ่มต้น)**: การออกจากระบบครั้งแรกจะคัดลอกทุกเซสชันหนึ่งครั้ง หลังจากนั้นทุกครั้งที่ออกจากระบบจะเขียนเฉพาะเซสชันที่เปลี่ยนจากครั้งก่อน ซึ่งมักเป็นไม่กี่ไฟล์และไม่กี่ MB และเสร็จเกือบทันที
- **ลบสำเนาหลังลงชื่อเข้า**: ทุกครั้งที่ลงชื่อเข้าจะลบสำเนา ทุกครั้งที่ออกจากระบบจึงต้องเขียนทุกเซสชันใหม่ หากมีประมาณ 300 เซสชันและ 10 โฟลเดอร์บัญชี/องค์กร นั่นคือเขียนราว 600 MB ทุกครั้งที่เปลี่ยนกะ บวกกับการลบไฟล์ราว 3,000 ไฟล์ภายหลัง

สิ่งที่ต้องแลกคือพื้นที่ดิสก์: สำเนาจะยังคงอยู่บนดิสก์และใช้พื้นที่ประมาณ (ขนาดรวมของไฟล์เซสชัน × จำนวนโฟลเดอร์บัญชี/องค์กร)

### ทำไมไม่ใช้จังก์ชันหรือฮาร์ดลิงก์

หากให้โฟลเดอร์ของทุกบัญชีชี้ไปยังโฟลเดอร์จริงโฟลเดอร์เดียว ก็ไม่ต้องคัดลอก แต่แอป Claude ตั้งใจปิดกั้นทั้งสองวิธีไว้:

- **จังก์ชันและลิงก์สัญลักษณ์**: ก่อนบันทึกทุกครั้ง แอปจะตรวจว่าโฟลเดอร์เซสชันเป็นโฟลเดอร์จริง และปฏิเสธการบันทึกหากเป็นลิงก์ (`Refusing non-directory at private dir path (symlink/file plant)`) เมื่อทดสอบกับแอปจริง อ่านรายการผ่านจังก์ชันได้ แต่การบันทึกเซสชันและงานตามกำหนดเวลาล้มเหลวทั้งหมด รวมถึงเซสชันที่เพิ่งสร้าง
- **ฮาร์ดลิงก์**: แอปถือว่าไฟล์ที่มีลิงก์มากกว่าหนึ่งไม่ปลอดภัย จึงปฏิเสธการเขียนลงไฟล์เหล่านั้นและเตือนเมื่ออ่าน อีกทั้งแอปบันทึกด้วยการเขียนไฟล์ชั่วคราวแล้วเปลี่ยนชื่อ ซึ่งจะทำให้ลิงก์ขาดทุกครั้งที่บันทึก

การตรวจสอบเหล่านี้มีไว้ป้องกันไฟล์หรือโฟลเดอร์ที่ถูกวางไว้จากภายนอก CCDC จึงไม่หลีกเลี่ยงการตรวจสอบเหล่านี้ แต่คัดลอกไฟล์ธรรมดาแบบเดียวกับที่แอปเขียนเอง

## สิ่งที่ต้องมี

- Windows 10 หรือ 11 และแอป Claude เดสก์ท็อป (ติดตั้งแบบ MSIX)
- [Node.js](https://nodejs.org) 18 ขึ้นไป

## การติดตั้ง

ดาวน์โหลดตัวติดตั้งจาก [Releases](../../releases) แตกไฟล์ แล้วเรียกใช้ `setup.cmd` ไม่ต้องใช้สิทธิ์ผู้ดูแลระบบ

- ติดตั้งไว้ที่ `%LOCALAPPDATA%\Programs\CCDC`
- สร้างทางลัด `Continuous Claude Desktop Code` บนเดสก์ท็อปและในเมนูเริ่ม
- แสดงใน การตั้งค่า > แอป > แอปที่ติดตั้ง ในชื่อ "Continuous Claude Desktop Code (CCDC)" และถอนการติดตั้งได้จากที่นั่น
- เริ่มทำงานในถาดระบบทันทีหลังติดตั้ง
- หากต้องการให้ CCDC เริ่มทำงานเมื่อลงชื่อเข้า Windows ให้ติดตั้งด้วย `setup.cmd /startup` หากต้องการยกเลิก ให้ใช้ `setup.cmd /nostartup` หากไม่ระบุตัวเลือกใด การติดตั้งใหม่จะคงค่าเดิมไว้
- การติดตั้งใหม่จะหยุด CCDC หากกำลังทำงานอยู่ แล้วแทนที่ไฟล์ ส่วนการตั้งค่าของคุณ (`ccdc.json`) จะยังคงอยู่
- การถอนการติดตั้งจะคงไฟล์เซสชันของ Claude และโฟลเดอร์สำรองของ CCDC ไว้ตามเดิม

หากต้องการใช้จากที่เก็บนี้โดยตรงโดยไม่ติดตั้ง ให้เรียกใช้ `ccdc-tray.vbs` หรือใช้บรรทัดคำสั่งด้านล่าง

## แอปถาดระบบ

ไอคอนตัว **C** สีส้มจะปรากฏในพื้นที่แจ้งเตือน (เป็นสีเทาขณะปิดการซิงค์อัตโนมัติ) คลิกเพื่อเปิดเมนู:

| เมนู | หน้าที่ |
| --- | --- |
| บรรทัดสถานะ | แสดงว่า CCDC กำลังเฝ้าดูการลงชื่อเข้าและออกจากระบบอยู่หรือไม่ |
| ซิงค์อัตโนมัติ (ตรวจจับการลงชื่อเข้า/ออก) | เปิดหรือปิดการคัดลอกและการล้างสำเนา |
| ย้ายเซสชันไปยังบัญชีตอนนี้ | รวมเซสชันทั้งหมดไว้ในโฟลเดอร์ของบัญชีเดียว จะถามยืนยันก่อนหากบัญชีนั้นไม่ได้ลงชื่อเข้าอยู่ |
| ลบสำเนาหลังลงชื่อเข้า | ปิดไว้ตามค่าเริ่มต้น (เก็บสำเนาไว้ ดูด้านบน) |
| ความเร็วในการคัดลอก/ลบ | เลือกได้ระหว่าง เร็ว (ไม่จำกัด), ปกติ (60 MB/s) และ ช้า (15 MB/s) ในโหมดปกติและช้า การลบจะจำกัดไว้ที่ 500 และ 100 ไฟล์ต่อวินาทีตามลำดับ |
| บรรทัดเวลาโดยประมาณ | แสดงเวลาที่การคัดลอกตอนออกจากระบบครั้งถัดไปจะใช้ หากตั้งให้ลบสำเนา จะแสดงเวลาที่ใช้ล้างหลังลงชื่อเข้าด้วย |
| Language | เลือกภาษาที่แสดง รายการนี้แสดงเป็นภาษาอังกฤษเสมอ และแต่ละภาษาในเมนูย่อยเขียนด้วยภาษานั้นเอง |
| ดูบันทึก | เปิด `%LOCALAPPDATA%\CCDC\watch.log` |
| ตั้งชื่อบัญชี (ccdc.json) | เปิดไฟล์ตั้งค่าเพื่อตั้งชื่อบัญชีให้อ่านง่าย |
| ออก | นำไอคอนออก หากกำลังคัดลอกอยู่ จะรอให้เสร็จก่อน |

จะมีการแจ้งเตือนเมื่อเริ่มคัดลอก (พร้อมเวลาโดยประมาณ) เมื่อคัดลอกเสร็จ เมื่อตรวจพบการลงชื่อเข้า และเมื่อล้างเสร็จ หากเลือกความเร็วที่ต่ำลง การคัดลอกจะใช้เวลานานขึ้น คนถัดไปจึงควรรอการแจ้งเตือน "คัดลอกเสร็จแล้ว" หรือรอตามเวลาโดยประมาณก่อนลงชื่อเข้า

เวลาโดยประมาณคำนวณจากสถานะปัจจุบันของโฟลเดอร์ และจากความเร็วในการคัดลอกและลบที่วัดได้บนพีซีเครื่องนี้ (เก็บไว้ใน `%LOCALAPPDATA%\CCDC\state.json`)

หากไม่เห็นไอคอนใน Windows 11 ให้ดูในไอคอนที่ซ่อนอยู่ (`^`) บนแถบงาน หากต้องการให้แสดงตลอด ให้เปิด Windows PowerShell ใน การตั้งค่า > การปรับให้เป็นแบบส่วนตัว > แถบงาน > ไอคอนถาดระบบอื่นๆ

### การใช้หน่วยความจำ

แอปถาดระบบเฝ้าดูบันทึกของ Claude ด้วยตัวเอง โดยอ่านเฉพาะส่วนที่เพิ่มเข้ามาตั้งแต่การตรวจครั้งก่อน Node.js ทำงานเฉพาะตอนคัดลอกหรือล้างสำเนา แล้วปิดตัวลงหลังเสร็จ นอกช่วงเปลี่ยนกะจึงมีเพียงแอปถาดระบบที่ทำงานอยู่ ขณะว่างอยู่ แอปจะคืนหน่วยความจำที่ไม่ได้ใช้ให้ Windows ประมาณนาทีละครั้ง (ใช้อยู่ราว 15 MB)

## การตั้งค่า

การตั้งค่าเก็บไว้ใน `ccdc.json` ในโฟลเดอร์โปรแกรม ค่าที่เปลี่ยนจากเมนูถาดระบบจะบันทึกลงไฟล์นี้ และมีผลตั้งแต่การคัดลอกหรือการล้างครั้งถัดไปโดยไม่ต้องรีสตาร์ท

```json
{
  "keepCopies": true,
  "speed": "fast",
  "language": "",
  "aliases": { "<first 8 characters of an account ID>": "<name>" }
}
```

| คีย์ | ค่า |
| --- | --- |
| `keepCopies` | `true` (ค่าเริ่มต้น): เก็บสำเนาไว้ `false`: ลบสำเนาหลังลงชื่อเข้า |
| `speed` | `"fast"` (ค่าเริ่มต้น), `"normal"`, `"gentle"` |
| `language` | เว้นว่างเพื่อใช้ภาษาตาม Windows หรือใส่รหัสภาษา เช่น `"ja"` เพื่อใช้ภาษานั้น |
| `aliases` | ชื่อที่แสดงสำหรับบัญชีในเมนูถาดระบบ (ใช้ 8 อักขระแรกของ ID บัญชี) |

## ภาษา

เมนูถาดระบบ การแจ้งเตือน คำเตือน และหน้าต่างติดตั้ง/ถอนการติดตั้ง จะใช้ภาษาที่แสดงของ Windows หรือภาษาที่เลือกไว้ใน **Language** ในเมนูถาดระบบ ภาษาที่รองรับ: อังกฤษ เกาหลี ญี่ปุ่น จีน (ตัวย่อและตัวเต็ม) สเปน ฝรั่งเศส เยอรมัน อิตาลี โปรตุเกส รัสเซีย ยูเครน โปแลนด์ ดัตช์ ตุรกี เวียดนาม อินโดนีเซีย ไทย อาหรับ และฮินดี ภาษาอื่นจะแสดงเป็นภาษาอังกฤษ

ข้อความทั้งหมดของอินเทอร์เฟซอยู่ในชีตเดียว [`locales.csv`](locales.csv): **หนึ่งแถวต่อหนึ่งภาษา** หนึ่งคอลัมน์ต่อหนึ่งข้อความ เปิดด้วย Excel หรือ Google ชีตได้ หากต้องการเพิ่มภาษา ให้เพิ่มหนึ่งแถว

- `lang`: ชื่อวัฒนธรรมของ Windows (`sv`, `pt-BR`, `zh-Hant` …) จะใช้แถวที่ตรงทั้งภาษาและภูมิภาคก่อน หากไม่มีจึงใช้แถวที่ตรงกับภาษา
- `name`: ชื่อภาษาที่เขียนด้วยภาษานั้น (`Svenska`) เมนู Language จะแสดงชื่อนี้
- เขียนการขึ้นบรรทัดใหม่ในเซลล์เป็น `\n` และคง `{0}`, `{1}` ไว้ (เป็นตำแหน่งที่ใส่ตัวเลขหรือชื่อ)
- เซลล์ว่างจะแสดงเป็นภาษาอังกฤษ ให้บันทึกไฟล์เป็น CSV แบบ UTF-8

ผลลัพธ์บรรทัดคำสั่งและ `watch.log` ยังคงเป็นภาษาอังกฤษ เพราะแอปถาดระบบเป็นผู้อ่าน

## บรรทัดคำสั่ง

```powershell
node ccdc.mjs status               # app state, settings, sessions per folder, free disk
node ccdc.mjs estimate             # how long the next sign-out copy / sign-in cleanup would take
node ccdc.mjs replicate --dry-run  # what a sign-out copy would write right now
node ccdc.mjs move [--to <acct>]   # gather every session into one account's folder (first 8 characters of the ID are enough)
node ccdc.mjs watch                # follow the app log in the foreground (the tray does this itself)
```

เมื่อจำเป็น แอปถาดระบบจะเรียกใช้งานแบบครั้งเดียวต่อไปนี้: `node ccdc.mjs signout`, `node ccdc.mjs signin --account <id> --org <id>` และ `node ccdc.mjs startup` (เพื่อให้ตรงกับสถานะปัจจุบันของ Claude เมื่อแอปถาดระบบเริ่มทำงานหรือเมื่อเปิดซิงค์อัตโนมัติอีกครั้ง)

## กฎการจัดการสำเนาซ้ำ

- หากเซสชันอยู่ในหลายโฟลเดอร์ จะใช้สำเนาที่มี `lastActivityAt` ล่าสุด สำเนาจะคงเวลาแก้ไขของต้นฉบับไว้ จึงรู้ได้ว่าสำเนาใดเหมือนกันจากขนาดและเวลาโดยไม่ต้องอ่านไฟล์
- เมื่อสำเนาที่ใหม่กว่าแทนที่ไฟล์ ไฟล์เดิมจะถูกย้ายไปที่ `ccdc-backups\<เวลา>\` ในโฟลเดอร์ข้อมูลของแอป
- เซสชันที่มีเครื่องหมาย `deleted_<id>` จะไม่ถูกคัดลอก และสำเนาในโฟลเดอร์อื่นจะถูกลบ
- บัญชี/องค์กรที่ลงชื่อเข้าเป็นครั้งแรกยังไม่มีโฟลเดอร์ จึงคัดลอกไปไว้ที่นั่นตอนออกจากระบบไม่ได้ ในกรณีนี้ เซสชันจะแสดงหลังบัญชีนั้นลงชื่อเข้าครั้งถัดไปหรือเมื่อรีสตาร์ทแอป

## ข้อควรระวัง

- CCDC อาศัยโครงสร้างไฟล์ภายในและข้อความบันทึกของแอป Claude เดสก์ท็อป การอัปเดตแอปอาจทำให้การทำงานเปลี่ยนไป
- ไฟล์เซสชันมีการตั้งค่าตัวเชื่อมต่อ (MCP) ของแต่ละบัญชี ตัวเชื่อมต่อบางตัวจึงอาจเชื่อมต่อไม่ได้เมื่อเปิดเซสชันจากบัญชีอื่น
- งานตามกำหนดเวลาไม่ได้ใช้ร่วมกันระหว่างบัญชี แต่ละโฟลเดอร์บัญชี/องค์กรเก็บงานของตัวเองแยกกัน
- ไม่ครอบคลุมการสลับบัญชีใน Claude Code CLI เพราะ CLI เปิดเซสชันใดก็ได้ใน `~/.claude/projects` ด้วย `--resume` อยู่แล้ว ไม่ว่าจะเป็นบัญชีใด
