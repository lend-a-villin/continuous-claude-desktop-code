# Continuous Claude Desktop Code (CCDC)

Claude 계정을 바꿔도 Claude 데스크톱 앱의 **Code** 세션이 사라지지 않게 해 주는 Windows 트레이 앱입니다.

Claude 데스크톱 앱은 계정·조직마다 Code 세션 목록을 따로 관리합니다. 그래서 다른 계정으로 로그인하면, 대화 기록은 PC에 그대로 남아 있는데도 세션 목록이 비어 보입니다. CCDC가 세션을 모든 계정으로 복사해 두므로, 다음에 어떤 계정으로 로그인하든 모든 세션이 보입니다.

비공식 프로그램으로, Anthropic과 관련이 없으며 Anthropic의 승인을 받지 않았습니다.

**[최신 버전 다운로드](../../releases/latest)** · Windows 10/11 · Node.js 18 이상 · 관리자 권한 불필요

## 사용 대상

- **공용 PC와 교대 근무.** 24시간 3교대로 운영되는 직장에서는 교대 조마다 다른 사람이 같은 자리(한 PC, 한 Windows 사용자)에 앉아 각자 자기 Claude 계정으로 로그인합니다. CCDC를 사용하면 다음 근무조가 앞 근무조가 하던 Code 작업을 그대로 이어받을 수 있습니다.
- **한 사람이 여러 계정을 쓰는 경우.** 같은 PC에서 개인 계정과 회사 계정을, 또는 여러 조직을 오가며 쓴다면 어느 계정으로 로그인하든 같은 Code 세션을 이어서 사용할 수 있습니다.

CCDC를 사용하면 이 PC에 로그인하는 모든 계정에서 이 PC의 모든 Code 세션이 보입니다. 서로의 세션을 보면 안 되는 환경에서는 CCDC를 사용하지 마세요. 회사(조직) 계정을 사용한다면 먼저 사내 정책을 확인하세요. CCDC는 회사 계정의 세션을 개인 계정 폴더로도 복사하며, 그 반대도 마찬가지입니다.

## 해결하는 문제

데스크톱 앱은 Code 세션 **목록**을 계정·조직마다 별도의 폴더에 저장합니다.

```
%LOCALAPPDATA%\Claude-Data\claude_<pkg>\claude-code-sessions\<accountUuid>\<orgUuid>\local_<id>.json
```

반면 **대화 내용**은 모든 계정이 함께 쓰는 `~/.claude/projects\...\<cliSessionId>.jsonl`에 저장됩니다. 그래서 다른 계정으로 로그인하면 대화 내용은 디스크에 그대로 있는데도 Code 세션 목록이 비어 보입니다.

## 동작 방식

앱은 **시작할 때와 로그인할 때만** 세션 폴더를 읽습니다(로그인할 때는 약 2초 사이에 두 번). 그 밖의 시점에 목록만 다시 읽게 할 방법은 없습니다. 로그아웃과 로그인은 모두 앱 자체 로그(`%LOCALAPPDATA%\Claude\Logs\main.log`)에 다음과 같이 기록됩니다.

- 로그아웃: `[account] Login-state transition (loggedOut: false → true ...)`
- 로그인: `[LocalSessionManager] Initialization succeeded — accountId=…, orgId=…`

CCDC는 이 로그를 지켜보다가 다음과 같이 동작합니다.

1. **로그아웃할 때**: 각 세션의 최신본을 모든 계정·조직 폴더에 복사합니다. 그래서 다음에 어느 계정으로 로그인하든 그 계정의 폴더에 세션이 이미 들어 있습니다. 이때 폴더에 없거나 오래된 세션만 복사합니다.
2. **로그인할 때**: 기본적으로 사본은 그대로 둡니다. "로그인 후 사본 삭제"를 켜 두었다면 앱이 목록을 다 읽을 때까지(마지막 로그인 기록 뒤 6초) 기다렸다가, 로그인한 계정의 폴더를 뺀 나머지 폴더에서 사본을 삭제합니다.

앱에서 삭제한 세션은 다른 폴더에서도 지워지므로, 다른 계정으로 로그인해도 다시 나타나지 않습니다.

CCDC는 복사하기 전에 디스크 여유 공간을 확인합니다. 복사에 필요한 공간에 512MB를 더한 만큼이 남아 있지 않으면, 아무것도 복사하지 않고 경고를 표시합니다.

### 기본적으로 사본을 남기는 이유

사본을 남기는 방식이 SSD에 가장 부담이 적습니다.

- **사본 유지(기본값)**: 처음 로그아웃할 때 모든 세션을 한 번 복사합니다. 그 뒤로는 로그아웃할 때마다 지난번 이후 바뀐 세션만 기록하므로, 보통 파일 몇 개(몇 MB)로 거의 바로 끝납니다.
- **로그인 후 사본 삭제**: 로그인할 때마다 사본을 지우므로, 로그아웃할 때마다 모든 세션을 다시 기록해야 합니다. 세션이 300개쯤이고 계정·조직 폴더가 10개라면, 교대할 때마다 약 600MB를 기록하고 그 뒤에 파일 약 3,000개를 지웁니다.

그 대가는 디스크 공간입니다. 사본이 디스크에 계속 남으므로 (세션 파일 크기 합계 × 계정·조직 폴더 수)만큼의 공간을 차지합니다.

### 정션이나 하드링크를 사용하지 않는 이유

모든 계정 폴더가 실제 폴더 하나를 가리키게 하면 복사할 필요가 없겠지만, Claude 앱은 그렇게 하는 두 가지 방법을 모두 의도적으로 막고 있습니다.

- **정션·심볼릭 링크**: 앱은 저장할 때마다 세션 폴더가 실제 폴더인지 확인하고, 링크이면 저장을 거부합니다(`Refusing non-directory at private dir path (symlink/file plant)`). 실제 앱으로 시험해 보니 정션을 거쳐 목록은 읽혔지만, 새로 만든 세션까지 포함해 모든 세션과 예약 작업을 저장하지 못했습니다.
- **하드링크**: 앱은 링크가 둘 이상인 파일을 안전하지 않은 파일로 봅니다. 그런 파일에는 쓰기를 거부하고, 읽을 때는 경고를 남깁니다. 또 앱은 임시 파일에 쓴 뒤 이름을 바꾸는 방식으로 저장하므로, 저장할 때마다 링크가 끊어질 수밖에 없습니다.

이 검사들은 밖에서 심어 놓은 파일이나 폴더를 막기 위한 장치이므로, CCDC는 이를 우회하지 않습니다. 대신 앱이 직접 만드는 것과 똑같은 일반 파일을 복사합니다.

## 요구 사항

- Windows 10/11과 Claude 데스크톱 앱(MSIX 설치판)
- [Node.js](https://nodejs.org) 18 이상

## 설치

[Releases](../../releases)에서 설치 파일을 내려받아 압축을 풀고 `setup.cmd`를 실행하세요. 관리자 권한은 필요하지 않습니다.

- `%LOCALAPPDATA%\Programs\CCDC`에 설치됩니다.
- 바탕화면과 시작 메뉴에 `Continuous Claude Desktop Code` 바로가기가 만들어집니다.
- 설정 > 앱 > 설치된 앱에 "Continuous Claude Desktop Code (CCDC)"로 표시되며, 제거도 여기서 합니다.
- 설치가 끝나면 바로 트레이에서 실행됩니다.
- Windows에 로그인할 때 자동으로 실행되게 하려면 `setup.cmd /startup`으로, 자동 실행을 끄려면 `setup.cmd /nostartup`으로 설치하세요. 옵션 없이 다시 설치하면 이전 설정이 유지됩니다.
- 다시 설치하면 실행 중인 CCDC를 종료하고 파일을 교체합니다. 설정 파일(`ccdc.json`)은 그대로 유지됩니다.
- 제거해도 Claude 세션 파일과 CCDC 백업 폴더는 그대로 남습니다.

설치하지 않고 이 저장소에서 바로 사용하려면 `ccdc-tray.vbs`를 실행하거나 아래 명령줄을 사용하세요.

## 트레이 앱

알림 영역에 주황색 **C** 아이콘이 표시됩니다(자동 동기화가 꺼져 있으면 회색). 아이콘을 클릭하면 메뉴가 열립니다.

| 메뉴 | 동작 |
| --- | --- |
| 상태 줄 | CCDC가 로그인·로그아웃을 감시하고 있는지 보여 줍니다. |
| 자동 동기화 (로그인/로그아웃 감지) | 복사와 정리를 켜거나 끕니다. |
| 계정으로 지금 옮기기 | 모든 세션을 한 계정의 폴더로 모읍니다. 그 계정이 로그인한 상태가 아니면 먼저 묻습니다. |
| 로그인 후 사본 삭제 | 기본값은 꺼짐입니다(사본을 남김, 위 설명 참고). |
| 복사·삭제 속도 | 빠르게 (제한 없음), 보통 (60MB/s), 천천히 (15MB/s) 중에서 고릅니다. 삭제 속도는 각각 제한 없음, 초당 500개, 초당 100개입니다. |
| 예상 시간 줄 | 다음 로그아웃 때 복사에 걸릴 시간을 보여 줍니다. 사본을 삭제하도록 설정했다면 로그인 후 정리 시간도 함께 보여 줍니다. |
| Language | 표시 언어를 고릅니다. 이 항목은 항상 영어로 표시되고, 하위 메뉴의 각 언어는 그 언어로 적혀 있습니다. |
| 로그 보기 | `%LOCALAPPDATA%\CCDC\watch.log`를 엽니다. |
| 계정 이름 붙이기 (ccdc.json) | 설정 파일을 열어 계정에 알아보기 쉬운 이름을 붙입니다. |
| 종료 | 트레이에서 아이콘을 없애고 종료합니다. 복사 중이면 끝날 때까지 기다립니다. |

복제를 시작할 때(예상 시간 포함), 복제가 끝났을 때, 로그인을 감지했을 때, 정리가 끝났을 때 알림이 표시됩니다. 속도를 느리게 설정할수록 복사가 오래 걸리므로, 다음 사람은 "복제 완료" 알림이 뜰 때까지, 또는 예상 시간만큼 기다렸다가 로그인하세요.

예상 시간은 폴더의 현재 상태와 이 PC에서 측정한 복사·삭제 속도(`%LOCALAPPDATA%\CCDC\state.json`에 저장)를 바탕으로 계산합니다.

Windows 11에서 아이콘이 보이지 않으면 작업 표시줄의 `^`(숨겨진 아이콘)를 확인하세요. 아이콘이 항상 보이게 하려면 설정 > 개인 설정 > 작업 표시줄 > 기타 시스템 트레이 아이콘에서 Windows PowerShell을 켜세요.

### 메모리 사용

앱 로그는 트레이가 직접 감시하며, 지난번 확인 이후 추가된 부분만 읽습니다. Node.js는 복사하거나 정리하는 동안에만 실행되고 작업이 끝나면 종료되므로, 교대와 교대 사이에는 트레이만 실행됩니다. 트레이는 대기 중일 때 약 1분마다 쓰지 않는 메모리를 Windows에 반환하며, 이 상태의 메모리 사용량은 약 15MB입니다.

## 설정

설정은 프로그램 폴더의 `ccdc.json`에 저장됩니다. 트레이 메뉴에서 바꾸면 이 파일에 저장되고, 프로그램을 다시 시작하지 않아도 다음 복사나 정리부터 적용됩니다.

```json
{
  "keepCopies": true,
  "speed": "fast",
  "language": "",
  "aliases": { "<계정 ID 앞 8자리>": "<이름>" }
}
```

| 키 | 값 |
| --- | --- |
| `keepCopies` | `true`(기본값): 사본을 남깁니다. `false`: 로그인 후 사본을 삭제합니다. |
| `speed` | `"fast"`(기본값), `"normal"`, `"gentle"` |
| `language` | 비워 두면 Windows 표시 언어를 따릅니다. `"ja"` 같은 언어 코드를 넣으면 그 언어로 표시됩니다. |
| `aliases` | 트레이 메뉴에 표시할 계정 이름입니다. |

## 언어

트레이 메뉴, 알림, 경고 창, 설치·제거 창은 Windows 표시 언어나, 트레이 메뉴의 **Language**에서 고른 언어로 표시됩니다. 지원 언어는 영어, 한국어, 일본어, 중국어(간체·번체), 스페인어, 프랑스어, 독일어, 이탈리아어, 포르투갈어, 러시아어, 우크라이나어, 폴란드어, 네덜란드어, 튀르키예어, 베트남어, 인도네시아어, 태국어, 아랍어, 힌디어입니다. 그 밖의 언어는 영어로 표시됩니다.

화면에 나오는 모든 문구는 시트 한 장([`locales.csv`](locales.csv))에 들어 있습니다. **한 줄이 한 언어**이고, 열은 문구 항목입니다. Excel이나 Google 시트에서 열어 편집할 수 있으며, 언어를 추가하려면 한 줄만 추가하면 됩니다.

- `lang`: Windows 문화권 이름(`sv`, `pt-BR`, `zh-Hant` 등)을 적습니다. 언어와 지역이 모두 맞는 줄을 먼저 사용하고, 없으면 언어만 맞는 줄을 사용합니다.
- `name`: 그 언어로 적은 언어 이름(`Svenska`)입니다. Language 메뉴에 이 이름이 표시됩니다.
- 칸 안에서 줄을 바꾸려면 `\n`으로 적고, `{0}`, `{1}`(숫자나 이름이 들어갈 자리)은 그대로 두세요.
- 빈 칸은 영어 문구로 표시됩니다. 파일은 UTF-8 CSV로 저장하세요.

명령줄 출력과 `watch.log`는 트레이가 읽어 들이므로 영어로 고정되어 있습니다.

## 명령줄

```powershell
node ccdc.mjs status               # 앱 상태, 설정, 폴더별 세션 수, 남은 디스크 공간
node ccdc.mjs estimate             # 다음 로그아웃 복사와 로그인 후 정리에 걸릴 시간
node ccdc.mjs replicate --dry-run  # 지금 로그아웃하면 복사될 내용
node ccdc.mjs move [--to <acct>]   # 모든 세션을 한 계정의 폴더로 모으기 (계정 ID 앞 8자리면 충분)
node ccdc.mjs watch                # 앱 로그를 포그라운드에서 감시 (트레이가 같은 일을 자체적으로 수행)
```

트레이는 필요할 때 다음 작업을 한 번씩 실행합니다. `node ccdc.mjs signout`, `node ccdc.mjs signin --account <id> --org <id>`, `node ccdc.mjs startup`(트레이를 시작하거나 자동 동기화를 다시 켰을 때 앱의 현재 상태에 맞춤).

## 중복 처리 규칙

- 같은 세션이 여러 폴더에 있으면 `lastActivityAt`이 가장 최근인 사본을 남깁니다. 사본은 원본의 수정 시각을 그대로 가지므로, 두 사본이 같은지는 내용을 읽지 않고 크기와 시각만으로 판단합니다.
- 더 새로운 사본으로 파일을 바꿀 때는 이전 파일을 앱 데이터 폴더의 `ccdc-backups\<시각>\`으로 옮깁니다.
- `deleted_<id>` 표시가 있는 세션은 복사하지 않으며, 다른 폴더에 있는 사본은 삭제합니다.
- 처음 로그인하는 계정·조직은 아직 폴더가 없어서, 로그아웃할 때 그곳에는 복사할 수 없습니다. 이 경우 세션은 그 계정의 다음 로그인 때나 앱을 다시 시작한 뒤에 표시됩니다.

## 주의 사항

- CCDC는 Claude 데스크톱 앱의 내부 파일 구조와 로그 문구에 의존합니다. 앱이 업데이트되면 동작이 달라질 수 있습니다.
- 세션 파일에는 계정별 커넥터(MCP) 설정이 들어 있어서, 다른 계정에서 세션을 열면 일부 커넥터가 연결되지 않을 수 있습니다.
- 예약 작업은 공유되지 않으며, 계정·조직 폴더마다 따로 보관됩니다.
- Claude Code CLI의 계정 전환은 다루지 않습니다. CLI는 계정과 상관없이 `~/.claude/projects`에 있는 어떤 세션이든 이미 `--resume`으로 열 수 있습니다.
